# Kaggle ConnectX 强化学习竞赛

## 竞赛简介

Kaggle ConnectX 是一个基于重力四子棋（Connect Four）的强化学习竞赛.任务目标是在固定棋盘环境中设计智能 Agent，使其能够与其他选手提交的策略进行对战，并在有限推理时间内做出稳定决策.

## 技术方案

### DQN 方法

在探索初期，我首先实现了 Deep Q-Network 方法：

- **状态编码**：将 6×7 的棋盘状态转换为张量表示
- **网络架构**：采用卷积神经网络提取特征，并通过全连接层输出动作价值
- **训练技巧**：引入经验回放与目标网络以提升训练稳定性

### AlphaZero 方法

为了提升博弈能力，我进一步实现了 AlphaZero 风格的训练与搜索流程：

- **搜索算法**：使用 Monte Carlo Tree Search (MCTS) 进行动作规划
- **双头网络**：策略网络预测落子概率，价值网络评估当前局面胜率
- **自对弈**：通过自我博弈不断生成高质量的训练数据

### 排名表现

经过多轮迭代，Agent 取得了历史最高排名 **19/241 名**.这一结果表明，在有限推理时间和离散动作空间约束下，搜索策略、状态编码与训练稳定性对最终表现都有显著影响.

## 关键技术细节

- **训练稳定性**：通过学习率调度、梯度裁剪与目标网络机制降低训练发散风险；
- **搜索效率**：优化 MCTS 搜索逻辑，在有限推理时间内扩展更多高价值分支；
- **博弈策略**：结合对手建模和开局策略，提高 Agent 在实战对局中的鲁棒性.

## 项目结果

- 完成从棋盘状态编码、价值/策略网络训练到 MCTS 搜索的 Agent 实现；
- 比较 DQN、AlphaZero 等方法在训练稳定性、搜索效率与对战表现上的差异；
- 历史最高排名达到 **19/241**，验证了所实现策略在该竞赛环境中的有效性.
