# 概述（Overview）

**EVA: Deciphering RNA Design Principles** 是一项面向 RNA 序列理解与设计的 AI4Bio 研究工作.项目目标是构建具备长上下文建模能力的生成式基础模型，用于学习 RNA 序列中的设计规律，并进一步支持序列生成、任务适配与可验证的下游生物学问题.

我在该项目中参与模型训练与微调相关工作，并负责项目网站的前后端实现与工程支撑.该工作目前投稿至 **Nature Machine Intelligence**，预印本已在 bioRxiv 发布，代码仓库见 [GENTEL-lab/EVA](https://github.com/GENTEL-lab/EVA).

## English Summary

**EVA: Deciphering RNA Design Principles** is an AI4Bio research project focused on RNA sequence understanding and design. The project develops a long-context generative foundation model for learning RNA design principles, supporting sequence generation, downstream adaptation, and biologically meaningful evaluation.

My contributions include collaboration on model training and fine-tuning, as well as full-stack implementation of the project website and engineering support for the project release. The manuscript is currently under review at **Nature Machine Intelligence**; the preprint is available on bioRxiv, and the code is released at [GENTEL-lab/EVA](https://github.com/GENTEL-lab/EVA).

## 研究与工作（Research and Work）

EVA 的核心问题是：如何让生成式模型在更长上下文中理解 RNA 序列，并从大规模序列数据中学习可迁移的设计原则.与只面向单一任务的预测模型不同，基础模型需要同时具备序列表示、生成、微调和迁移能力，因此对数据组织、上下文长度、训练稳定性和评估体系都有更高要求.

在项目推进中，我主要参与以下工作：

- 协同开展 RNA 长上下文生成式基础模型的训练与微调；
- 支持模型在 RNA 序列理解、生成与设计相关任务上的实验整理；
- 实现项目网站前后端，支持研究内容、模型资源与项目材料的发布；
- 配合预印本、代码仓库与项目展示材料的工程化整理.
